# C 语言版（控制台）

用 MSVC 编译的原生版本，体积 168 KB，无任何运行库依赖（AES 用系统 BCrypt）。

## 编译

双击 `build-c.bat`，或在 VS2022 x64 开发者命令提示符里：

    cl /O2 /utf-8 ncm2mp3.c bcrypt.lib

## 用法

把 .ncm 文件或文件夹**拖到 exe 图标上**即可，输出在同目录。
也可以命令行：

    ncm2mp3.exe <文件或文件夹> [更多...]

## 与 Python 版的区别

| | C 版 | Python 版 |
|---|---|---|
| 体积 | 168 KB | 15.8 MB |
| 界面 | 无（控制台） | 有图形界面 |
| 拖拽方式 | 拖到 exe 图标 | 拖进窗口 |
| 依赖 | 无 | 打包了 Python 运行时 |
| 速度 | 很快 | 快 |

解密算法完全一致，输出文件逐字节相同。
